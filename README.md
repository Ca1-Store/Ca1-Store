# موقع CA Store — دليل التشغيل

## 1) الباكند (Railway)
1. استبدل ملف الباكند بـ `backend-with-store.js` (هو ملفك + نظام المتجر). عند أول تشغيل ينشئ الجداول ويضيف منتجاتك الـ 11 تلقائياً بروابط PayPal كما هي.
2. أضف في Railway → Variables:
   - `ADMIN_DISCORD_ID` : آيدي حسابك (موجود عندك) — هو الأدمن الأساسي.
   - `STORE_ADMIN_IDS` : (اختياري) آيديات أدمنز إضافيين مفصولة بفاصلة.
   - `WEBSITE_URL` : رابط الموقع، مثل `https://www.ca-store.store`
   - `EXTRA_ORIGINS` : (اختياري) نطاقات إضافية مسموحة، مفصولة بفاصلة.
3. في Discord Developer Portal → OAuth2 → Redirects أضف: `https://www.ca-store.store/auth-callback.html`

### الدفع التلقائي (PayPal)
- أضف في Railway: `PAYPAL_CLIENT_ID` و `PAYPAL_CLIENT_SECRET` (من تطبيق Live في developer.paypal.com).
- لا تحتاج ويبهوك جديد. الباكند يلتقط الدفعة عند رجوع العميل، يسجّل الشراء، يمنح الرتبة، يرسل الرسالة الخاصة ويكتب في قناة السجل.
- `WEBSITE_URL` يجب أن يكون رابط موقعك الفعلي لأن PayPal يرجّع العميل إليه.
- إذا لم تضف المفتاحين يعمل الموقع بالروابط القديمة تلقائياً كاحتياط.
- للتجربة بدون أموال: `PAYPAL_ENV=sandbox` مع مفاتيح Sandbox.

## 2) رفع الموقع
- الموقع ملفات ثابتة (HTML/CSS/JS) — ارفع المجلد كله على أي استضافة ثابتة (Cloudflare Pages / Netlify / GitHub Pages / Vercel).
- افتح `js/config.js` وعدّل `API` (رابط Railway) و`DISCORD_INVITE`.
- ضع صور المنتجات في `assets/products/`.

## 3) لوحة الأدمن
- ادخل `/admin.html` بحساب ديسكورد الأدمن (يظهر أيضاً «لوحة التحكم» في قائمة حسابك).
- **المنتجات**: إضافة / تعديل / حذف، تعديل السعر مباشرة من الجدول، ترتيب بالأسهم، وتغيير الحالة (متوفر / غير متوفر / مخفي).
- **رابط الدفع** مطلوب لأي منتج «متوفر» ويجب أن يبدأ بـ https (نفس روابط PayPal القديمة).
- **التقييمات**: حذف أي تقييم. **المشتريات**: تسجيل شراء يدوي بآيدي العميل ليتمكن من التقييم.

## 4) نظام التقييمات
يقيّم فقط من اشترى: إما عن طريق تسجيل الشراء (الويبهوك أو يدوياً من لوحة الأدمن)، أو لأن لديه رتبة النسخة (CA-1..CA-5) في ديسكورد. تقييم واحد لكل عميل لكل منتج ويمكنه تعديله أو حذفه.

## 5) أمان
- لا تضع أي مفاتيح في ملفات الموقع. صلاحيات الأدمن تُتحقق من الباكند فقط.
- غيّر `WEBHOOK_SECRET` و`JWT_SECRET` لقيم قوية.
